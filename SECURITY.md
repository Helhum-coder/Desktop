# Security Policy

## Reporting Security Vulnerabilities

The security and safety of this project and its contributors is our top priority.

### How to Report a Security Issue

If you discover a security vulnerability or have safety concerns, please report
them responsibly:

1. **DO NOT** open a public issue
2. Contact the repository owner directly through GitHub
3. Provide detailed information about the concern
4. Allow reasonable time for the issue to be addressed

### What to Report

We take all security and safety concerns seriously, including:

- Security vulnerabilities in code
- Safety concerns for contributors
- Potential threats or harassment
- Intellectual property violations
- Any form of abuse or misconduct

### Our Commitment

We are committed to:

- Acknowledging receipt of your report promptly
- Investigating all reports thoroughly
- Taking appropriate action to address valid concerns
- Protecting the privacy and safety of all reporters
- Maintaining a safe environment for all contributors

### Response Time

We aim to respond to security reports within 48 hours and will keep you informed
throughout the resolution process.

### Safe Environment

This project is committed to maintaining a safe, welcoming, and harassment-free
environment for everyone, regardless of:

- Age, body size, disability, ethnicity
- Gender identity and expression
- Level of experience, education
- Nationality, personal appearance, race, religion
- Sexual identity and orientation

Any behavior that makes participants feel unsafe will not be tolerated.

## Legal Protections

All intellectual property rights are protected and enforced. Any violations
will be taken seriously and may result in legal action.

## Support

If you have experienced abuse or feel unsafe, please reach out. Your concerns
will be treated with the utmost seriousness and confidentiality.

---

**Remember**: Everyone deserves to work in a safe environment free from abuse,
harassment, and threats. We stand firmly behind this principle.
